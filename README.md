# svg-road-sign-generator-native-app

React Native (Expo, TypeScript) mobile app version of
[svg-road-sign-generator-frontend](https://github.com/bradmkjr/svg-road-sign-generator-frontend).
Talks to the same `svg-road-sign-generator-backend` REST API.

## Run
- `npm install`
- `npm start` — Expo dev server (scan the QR code with Expo Go, or press `i` / `a` / `w`)
- `npm run ios` / `npm run android` / `npm run web`

## Status
Freshly scaffolded (`create-expo-app`, blank TypeScript template). No screens or API
integration ported yet — see the frontend repo for the feature set to mirror.
